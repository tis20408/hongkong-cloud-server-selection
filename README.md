### API 服务和开发环境

API 服务通常需要关注：

* CPU 响应能力
* 内存容量

建议不要只看带宽数字。高带宽并不代表应用一定更快，应用架构、数据库优化和代码效率同样影响响应速度。

香港节点通常因为距离较近而被用于面向大陆用户的业务，但实际效果取决于具体线路和网络环境。

如果你的用户主要来自大陆，建议关注：

* 路由类型
* 延迟表现

* 高峰时期稳定性

不要只根据服务器所在地判断速度。

### 1GB 内存香港云服务器够用吗？

取决于应用。

* 静态网站
* 简单博客

如果应用涉及：

* 数据库读写
* 文件处理
* 高频访问

* 新项目测试

* 临时业务
